Chrome에서 직전0.500초와 명중0.517초를 직접 비교, 844×300 혼합 편성의 피격/방어/처치·진행과 가로 넘침 없음, 오류/경고 없음 확인. 실제Android 성능/발열과 기존 밸런스 완주 재시험은 이번 표시 변경 범위에서 제외한다.
