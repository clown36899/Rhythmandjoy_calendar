기존 보스 원화와 전신 셀 방식을 따라 새 4×4 투명 시트를 생성했다. 6장 걷기, 6장 박치기, 4장 우박 시전이며 공통 크롭·발 원점을 사용한다. 실제 0.28초 박치기 명중과 우박의 기존 준비/명중 시계를 그대로 읽는다. Scene와 도감은 bossPose 하나를 공유하고 관절 변형을 추가하지 않는다. 시전 때 몸을 세우는 셀까지 같은 스케일로 보이도록 프레임 공통 여백을 반영했다. 자세별 기존 상처 앵커도 맞췄다. 소 48칸, 모두 GROUND542, 독립 공격과 적 수치는 유지한다.

## 설정과 화면

제목/상단 메뉴 줄을 제거하고 오른쪽 위에 설정·일시정지 버튼만 남겼다. 기존 수련·필살기 편성·도감·전체화면·설치 안내는 설정 모달로 이동했다. 중첩 창을 닫아도 마지막 창을 닫기 전에는 전투가 재개되지 않는다. 수동 일시정지는 설정을 열었다 닫아도 유지한다. 수련은 기존 45 비용과 1회 규칙을 사용한다. 게임 도중 편성 변경 금지도 유지한다.

Soundscape 단일 AudioContext/음악 루프를 재사용해 음악·효과음 선택을 분리했다. 음악을 껐다 켜면 기존 위치에서 재개하며 효과음 토글이 음악을 끊지 않는다. 로딩 중 취소·음소거·재시작·동시 재생 제한을 유지한다. 기존 localStorage 방식에 소리 선택과 전체 음량만 저장한다. 저장 실패는 게임 실행을 막지 않는다.

## 검증 결과와 한계

기존 49개 검사 모두 통과. 기존 밀치기 검사에 모든 적 종류, 문 앞 8회 발구름, 돌진의 동일 대상 1회 피해·진입 대기·정지·처치 1회/승리를 포함했다. 기존 효과 검사에서 보스 6 걷기/6 박치기/4 시전, 알파1, 유한 좌표·GROUND542·모델 불변을 확인했다. 기존 오디오 검사를 음악만/효과음만/모두끔, 로딩 중 변경, 음악 위치 재개로 확장했다.

Chrome 실제 Scene 문 앞 재현에서 보스 ID2, x4235, alpha1을 유지한 채 발구름/돌진을 반복했고, 처치 후 kills1·won으로 종료했다. 이 화면 검사는 HP5000과 문 앞 배치를 사용한 로컬 전용 재현이며 일반 플레이 완주 기록과 구분한다. 시전 자세와 바닥 접지·상처를 시각 확인했다. 재현 도구는 공개 파일에 넣지 않는다.

기존 일반 모델 플레이 정책으로 혼합 기본 144.55초, 혼합 제어 140.55초, 소·토끼164.95초 완주, 무지원38.75초 실패. 여섯 무리×세 지형의 기준 전투력1.03배 검사 유지. 실제 플레이어 승률을 뜻하지 않는다.

Chrome에서 소리 두 토글과 새로고침 저장, 편성/도감 왕복, 전투 중 설정, 수련 후 복귀, 수동 일시정지 유지를 확인했다. 844×300 전투 높이238, 667×280 높이218로 기존보다44 증가, 하단 버튼높이52 유지·가로넘침 없음·드래그 이미지0. 작은 설정창은 본문만 스크롤된다. 전체화면 요청은 검증 브라우저에서 성공하지 않아 기존 설치 안내 대체 경로를 확인했다. 실제 Android 전체화면/기기 오디오 청감은 미검증이다. 변경 없는 DB/계정/결제·서버 설정 검사는 제외했다.

실행물만 소스와 미러 각각 커밋·푸시 후 배포한다. 기존 공개 범위를 유지하고 원격 기존 파일/후보 해시 비교, 복구 가능한 폴더 교체, 캘린더 보호 파일 불변을 검사한다.
