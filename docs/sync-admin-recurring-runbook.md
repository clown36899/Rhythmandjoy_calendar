# 관리자 정기대관 운영 기준

## 등록

1. `/sync-admin/`의 `정기대관 등록`을 연다.
2. 대관명, 예약자, 시작일·종료일을 입력한다. 한 번에 최대 366일이다.
3. 요일마다 홀과 시간을 추가한다. 예: 월요일 C홀 13:00~15:00, 금요일 C홀 16:00~17:00.
4. 5주차를 기본 포함하거나 제외한다.
5. `12개월 미리보기·충돌 검사`를 실행한다.
6. 빨간 충돌 날짜는 해당 날짜만 홀·시간·날짜를 변경하거나 제외하고 다시 검사한다.
7. 노란 5주차 제외 날짜는 그대로 두거나, 필요한 날짜만 다시 포함하고 재검사한다.
8. 충돌이 0건일 때 등록한다.

등록 버튼은 DB 원장 등록, 네이버 예약불가, 스페이스클라우드 관리자 예약을 한 묶음으로 만든다. 같은 요청을 다시 전송해도 요청 ID 기준으로 중복 생성하지 않는다.

단건 예약과 정기대관 모두 전송 직전에 요청 ID를 저장한다. 응답을 받지 못한 채 새로고침하거나 같은 내용을 다시 전송하면 같은 ID로 DB의 기존 처리 결과를 확인한다. 같은 ID에 실제 날짜·홀·시간·규칙·예외가 달라지면 서버가 거부하므로 화면을 새로고침하고 새 요청으로 등록해야 한다. API 오류나 충돌이 발생해도 브라우저 로컬 초안을 실제 일정처럼 만들지 않는다.

## 상태 색상

- 파랑: 등록 예정
- 빨강: 기존 DB 일정과 충돌
- 노랑: 5주차 또는 수동 제외
- 보라: 날짜별 홀·시간·날짜·포함 여부 변경
- 초록: 운영 중인 정기대관 묶음

색상 외에도 상태 문구와 건수를 함께 표시한다.

## 취소

정기대관 카드의 `일정 관리`에서 다음 범위를 선택할 수 있다.

- 선택 일정 취소
- 남은 일정 전체 취소(오늘 포함)

지난 일정은 선택하거나 취소할 수 없으며 운영 이력으로 보존한다. 일간 일정 상세에서도 오늘 이후 관리자 일정 하나만 취소할 수 있다. 취소 요청 후에는 일정을 바로 삭제하지 않는다. 스페이스클라우드 삭제와 네이버 예약 가능 복구가 모두 완료될 때까지 `취소 처리 중`으로 유지하고, 실제 반영 확인 뒤 `취소 완료`로 전환한다.

단건 취소는 화면 상단 상태 카드에서 `네이버 예약 가능 복구`와 `스페이스클라우드 일정 삭제`를 각각 확인한다. 일정표의 주황색 점선 블록은 아직 두 플랫폼 확인이 끝나지 않았다는 뜻이며, 완료되면 일정표에서 자동으로 사라진다. `확인 필요`가 표시되면 완료된 쪽은 다시 실행하지 말고 해당 카드의 `관련 오류 보기`로 실패한 플랫폼만 확인한다.

등록·취소 버튼은 처리 중 다시 누를 수 없다. 서버도 예약 상태를 잠근 뒤 작업을 만들기 때문에 같은 취소를 동시에 두 번 실행하지 않는다.

## 알림

관리자 다건 등록이 정상 완료됐을 때는 날짜 수만큼 Telegram을 보내지 않는다. 각 예약과 두 플랫폼 작업 상태는 관리자 DB 화면에서 확인한다. 실패나 재검사 필요 상태만 실제 문제가 난 예약별로, 상태나 원인이 새로 바뀔 때 한 건 발송한다.

## 부분 변경 원칙

등록 전에는 미리보기의 한 날짜만 바꾼다. 이미 등록 완료된 일정의 시간·홀 이동은 `기존 날짜 취소`와 `새 날짜 등록` 두 작업으로 처리해야 하며, 변경되지 않은 나머지 정기대관 날짜는 다시 실행하지 않는다.
