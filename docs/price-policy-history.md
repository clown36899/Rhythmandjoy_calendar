# 리듬앤조이 가격 변경 기록

이 문서는 가격표 변경 내역을 Git에 남기기 위한 운영 기록이다. 관리자 패널의 DB 원장 매출은 예약/메일/플랫폼 화면에서 수집한 실제 결제금액을 기준으로 하며, 아래 가격표는 공개 안내표, 금액 미수집 일정 보정, 가격 변경 효과 분석에 사용한다.

## 원칙

- 실제 예약 매출은 `rhythmjoy_booking_ledger.gross_amount` 또는 `price` 원장값을 우선한다.
- 가격표 변경은 이미 확정되어 원장에 금액이 들어간 예약의 매출을 다시 계산하지 않는다.
- 구글 캘린더 수기/현금 일정처럼 결제금액이 없는 예약만 당시 가격표로 추정 보정할 수 있다.
- 가격 변경 시 `www/calendar_set/calendar_v10/revenue-policy.js`, `www/calendar_set/calendar_v10/home_infopage/popup_night.html`, `www/sync-admin/api.php`의 `price_policy_seed_rows()`를 함께 갱신한다.
- 스페이스클라우드와 네이버 가격을 다르게 운영하지 않는 것을 현재 기준으로 한다.

## 변경 작업 체크리스트

1. 네이버 예약 가격표를 변경한다.
2. 스페이스클라우드 가격표를 같은 금액으로 변경한다.
3. 공개 가격표 `popup_night.html`을 변경한다.
4. 관리자/구글 보정 기준 `revenue-policy.js`를 변경한다.
5. 관리자 패널 가격 이력 `price_policy_seed_rows()`에 적용일 기준 행을 추가한다.
6. 배포 후 관리자 패널의 가격 변경 이력에서 전값->후값이 보이는지 확인한다.
7. 이후 들어온 예약이 실제 원장 금액으로 통계에 반영되는지 확인한다.
