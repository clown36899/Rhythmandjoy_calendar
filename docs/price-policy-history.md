# 리듬앤조이 가격 변경 기록

이 문서는 가격표 변경 내역을 Git에 남기기 위한 운영 기록이다. 관리자 패널의 DB 원장 매출은 예약/메일/플랫폼 화면에서 수집한 실제 결제금액을 기준으로 하며, 아래 가격표는 공개 안내표, 금액 미수집 일정 보정, 가격 변경 효과 분석에 사용한다.

## 원칙

- 실제 예약 매출은 `rhythmjoy_booking_ledger.gross_amount` 또는 `price` 원장값을 우선한다.
- 가격표 변경은 이미 확정되어 원장에 금액이 들어간 예약의 매출을 다시 계산하지 않는다.
- 구글 캘린더 수기/현금 일정처럼 결제금액이 없는 예약만 당시 가격표로 추정 보정할 수 있다.
- 가격 변경 시 `www/calendar_set/calendar_v10/revenue-policy.js`, `www/calendar_set/calendar_v10/home_infopage/popup_night.html`, `www/sync-admin/api.php`의 `price_policy_seed_rows()`를 함께 갱신한다.
- 스페이스클라우드와 네이버 가격을 다르게 운영하지 않는 것을 현재 기준으로 한다.

## 2026-09-30 관리자 반영 범위

- 기존 구현 있음: 예약 카드·매출은 `eventGrossAmount()` / `ledger_gross_amount()`로 실제 원장 금액을 읽는다. 가격 이력은 `rhythmjoy_price_policy_history`와 기존 seed를 재사용한다.
- 관리자 참고표의 고정 가격 연결만 기존 DB 가격 이력으로 교체했다. 별도 가격 계산기·필드·테이블·예약·작업을 만들지 않는다.
- 신규 예약도 실제 수집된 결제금액을 집계한다. 10,000원 기준을 기존 예약에 일괄 곱하거나 금액 미수집 예약을 자동 추정하지 않는다. 플랫폼 변경 이전에 받은 예약이 뒤늦게 수집돼도 원래 결제금액을 사용한다.
- 동일 예약 재수집은 기존 원장 식별·upsert 경로를 그대로 사용한다. 이번 반영으로 원장 금액·예약 식별·자동화 큐를 변경하지 않는다.
- 최초 요청에 따라 관리자 패널을 반영한 뒤, 같은 날 추가 요청으로 공개 요금 팝업과 예약 안내 페이지의 A홀 평일 낮 가격도 10,000원으로 변경했다. PC·모바일 진입점의 캐시 버전도 갱신했다. 네이버·스페이스클라우드는 운영자가 변경하며, 레거시 보정 도구의 `revenue-policy.js`는 기존 예약 보정에 영향을 주지 않도록 유지한다.
- 검증: 기존 PHP 자체 검사(원장 식별·단건/정기 예약 재시도 중복 방지·수수료·취소 경로) 통과. 관리자 참고표의 최신 이력 선택·미래 이력 제외·다른 방·API 미수신 시 기존 참고값과 신규/기존 실제 금액·금액 미수집 경계를 확인했다. 예약 수집·원장 쓰기·큐는 수정하지 않아 외부 예약 생성/취소 시험은 제외했다.

## 변경 작업 체크리스트

1. 네이버 예약 가격표를 변경한다.
2. 스페이스클라우드 가격표를 같은 금액으로 변경한다.
3. 공개 가격표 `popup_night.html`을 변경한다.
4. 관리자/구글 보정 기준 `revenue-policy.js`를 변경한다.
5. 관리자 패널 가격 이력 `price_policy_seed_rows()`에 적용일 기준 행을 추가한다.
6. 배포 후 관리자 패널의 가격 변경 이력에서 전값->후값이 보이는지 확인한다.
7. 이후 들어온 예약이 실제 원장 금액으로 통계에 반영되는지 확인한다.
