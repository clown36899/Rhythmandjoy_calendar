# v43 — 사용자 원화와 비대칭 돌길 7장

수정 전 판정: 기존 구현 일부 있음. AREAS가 원화/지형을 소유하고 Scene의 preload → create/resize → drawLandscape가 기존 배경/돌길/반사 풀을 소유한다. ROAD_SECTIONS는 4장의 고정 구간이고 7장 순환 경로만 없었다. data의 선택 원화에 panorama와 roadTiles를 연결하고 동일 Scene 풀을 재사용했다. 별도 지형/충돌/전투/시간/DB/큐/운영 소유자는 만들지 않았다.

표시 경로: stage/카메라 offset → AREAS 원화 및 지형 선택 → 기존 Scene 이미지·물·발판 배치 → 브라우저 canvas. 기준 데이터는 GROUND542, PARALLAX.far .035, PARALLAX.ground 1, 원화 종횡비, 타일 너비 합2097/높이224/발48이다. 실제 모델의 이동·HP·명중·소환·보상·저장에는 쓰기 경로가 없다.

직접 호출부 update/drawLandscape/resize/preload와 기존 effects의 접지·반사·배경 검사, app의 stage/모달/드래그 가드를 조사했다. blame 1721bcbd는 원경 반복·반전 제거와 고정 도로, 7034a859는 지형에 따른 반사/바닥 표시, b6e57f27는 단계별 그림 및 발판 높이를 도입했다. 최초 보호인 비대칭 원화/모델과 표시의 분리/공통 발 높이를 유지한다. 새 타일은 원본 순서 1→7→1이며 flip 없이 카메라 좌표만 순환한다. 다른 단계의 4구간과 .5px 가장자리 여유는 유지한다.

사용자가 준 그림을 내장 image_gen으로 편집했다. 그림 안의 사람/동물 및 별도 돌길과 중복될 고정 전경을 제거하고 강물로 복원했다. 달/산/소나무/누각/안개/색/붓결을 유지한 inwang-user-plate-v43.png에 기존 far 풀 하나를 사용한다. 원화에 이미 있는 달/안개/소나무/물반사를 중복하는 기존 장식은 panorama 원화일 때 숨긴다. 시뮬레이션과 HUD의 skyState 시계는 유지하며 그림 속 달은 원화의 위치에 남는다. 타일 7장은 이전 내장 image_gen의 연결부 재도색 결과를 그대로 복사한다. 원본과 두 프롬프트, 타일 메타데이터는 design/stage1-v43에 보존한다.

기존 배경 검사만 확장했다. 2096.5/2097/2097.5 및 두 번째 반복/후진/인트로 카메라 범위에서 정확한 연결, 반전 없음, 발542, 모델 불변, 추가 draw 할당 없음 및 기존 2~5번 복귀를 검증한다. 90/90 자동검사와 git diff --check 통과. Chrome 실제 Scene도 동일 경계에서 틈0/발542/모델 불변, 모든 단계 원화와 지형 복귀를 확인했다. 1280×720,844×300,667×280의 시작/중간/문 앞 화면을 확인하고 작은 가로 화면 넘침0/드래그 이미지0/콘솔 오류0을 확인했다. 기존 apple-mobile-web-app-capable meta의 브라우저 폐기 예정 경고1개는 이 작업 전부터 존재한다.
