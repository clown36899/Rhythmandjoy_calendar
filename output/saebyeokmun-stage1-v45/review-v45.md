# v45 — 분리 배경, 전장 미니맵과 화면 경계

수정 전 판정: 기존 구현 일부 있음. AREAS/Scene far·middle·moon·mists·detailJoin와 skyState 시계를 재사용한다. 제공 원화의 달/구름/원경/근경만 분리해 연결하고 근경 오른쪽 연장 원화를 추가했다. 배경 깊이는 하늘·원경산·근경산3층, 달/구름은 하늘 내부의 독립 자산이다. 근경2장의 원본 너비 합3886px에서 공통160px을 겹쳐3726px로 이어진다. 두 투명 연결부가 같은 좌표에서 교차 페이드하며 좌우 반전은 없다. 산의 시간 애니메이션은 없고 카메라에 원경 .035/근경 .34, 돌길1 배율을 적용한다. 달은 기존 skyState, 구름은 같은 model.time을 읽어 흐르며 일시정지 시 시간이 멈춘다. 기존 돌길7장/발542와 다른 단계 복귀를 유지한다.

소환/체력도 기존 UNITS와 Journey.addAlly/summon 및 app onFrame을 재사용한다. 미니맵 구현은 없어서 기존 control-deck의 방향 버튼과 소환 버튼 사이에 읽기 전용 SVG 하나를 연결했다. 점과 화면 범위는 실제 Journey 위치/생존 목록의 투영이고 별도의 이동 좌표나 전투 시계는 없다. 모든 UI 그림/미니맵은 드래그 불가. 가득 찬 소환 버튼은 state=full, opacity1이며 개별10명/총50명을 표시한다.

표시/동작 경로와 기준: 소환 클릭·wave cursor → Journey 비용/쿨다운/종류·전체 한도 판정 → addAlly/spawn의 세계 좌표와 entering 상태 → step의 최초 걸어오기/실제 전투/경계 처리 → Scene·미니맵 표시. 최초 아군은 왼쪽 밖, 적은 오른쪽 밖에서 걸어 들어온다. 들어온 아군은 화면 양쪽 경계에 제한되며 순환하지 않는다. 적은 왼쪽 밖으로 완전히 나가면 같은 개체를 오른쪽 밖으로 옮겨 걸어 들어오게 한다. ID/HP/maxHP/출생시간/처치수/보상은 보존하고 진행 중 근접 자세와 접촉만 해제한다. 기존 투사체 목표/55거리 보호가 순환한 목표에 대한 오명중을 막는다. 적의 밀치기는 진입 중이면 위치를 유지하고, 진입 후에는 화면 오른쪽 및 원래 문 경계를 넘지 않는다. 정적인 문은 제외하며 주인공의 세계 거리·자동/수동 이동과 실제 문 파괴 후 완료는 유지한다.

관련 심볼·직접 호출부·기존 검사와 좁은 이력: eb1d19e의 사용자 단일 원화와7장 도로,49d44c99의 비대칭 native 원화 겹침,9282551f의 공통 달 시계/고정 문,22b144ca의 미진입 밀치기 보호,9b2203bf의 접촉 유지/자유 이동,63472138의 특수능력 포함 적 예산,eed7b11의 무료 조력 합류를 확인했다. 모델/표시 분리, 대상고정·명중/비용/보상1회, 공통발, 웨이브 비중첩, 무료조력1회, 구매/저장·모달/오디오 소유를 유지한다.

새 책임의 정확한 빈틈: 기존 모델은 화면 너비를 몰라 세계 문에서만 적이 등장하고 screen crossing을 판단할 수 없었다. Scene이 viewport 입력만 전달하고 실제 경계/최초 진입은 Journey가 단독 소유한다. entering은 첫 진입과 진입 후 오른쪽 밀치기 보호를 구분하며 재시작으로 초기화한다. 무료 조력은 과거 wave cursor만으로는 '가득 차서 대기'와 '이미 합류'를 구분할 수 없어 Journey에 해당 wave index→합류 여부 Map을 두고 용량이 생기면1회 처리한다. 외부 작업 큐·DB·저장 필드·마이그레이션은 없다. 종류별10명/전체50명 판정은 atSummonLimit 하나를 버튼과 실제 생성이 공유하고 무료 조력도 포함한다. 기존 구조를 병렬로 복제한 전투/소환/이동 관리자는 없다.

체력 경로: UNITS의 실제 동료 HP → unitStats/회복 상한/UI → waveBalance 기준 전투력 → 적 powerScale/실제 HP·출력. 요청은 소환 동료만30%감소이며 주인공200은 유지한다. 같은 데이터를 단순 감소하면 적도 sqrt(.7)배로 약해지는 부작용이 있어, waveBalance에서 원래 적 예산을 유지한다. 기존30개 stage/wave 배율을 fixture로 고정해 변경 전 값과1e-12 이내 일치를 검증했다. 소171.5/도령42/토끼33.6/선비39.2/의원43.4, 모든 다른 동료도 같은 .7배다. 체력은 소수1자리로 표시 가능한 정확한 값을 사용한다.

선택한 검증: 기존90개를 확장하고 신규 책임4개만 추가하여94/94 통과. 배경은 시간 변화에 달/구름만 이동, 반복 시점 고정, 산 카메라 속도, native 연결/투명알파, 다른 단계 복귀 및 모델 불변을 확인했다. 소환은50명/종류10명, 한도 거절 시 ID·비용·쿨다운/소환수 보존, 사망 후 빈 자리/재시작, 대기 조력1회 및 상한을 확인했다. 경계는 양쪽 아군 제한·벽 앞 보행거리, 화면 밖 최초 이동, 적 반복 후 동일개체와HP/보상 보존, 밀치기 진입/진입후, 정적인 문, 순환 이전 투사체의 빗나감, 일시정지/재시작을 확인했다. 기존 정상 조작 완주 검사를 무화면·1200·1914 폭 모두 실제 viewport 입력으로 확장하여5단계 각각 완주/문파괴/자원상한을 확인했다. 증가한 병력이 보스 특수능력 이전에 처치할 수 있으므로 완주검사의 필수 특수능력 발생 조건은 제거하고, 기존 별도 특수능력 명중/취소/방어 검사는 유지했다.
