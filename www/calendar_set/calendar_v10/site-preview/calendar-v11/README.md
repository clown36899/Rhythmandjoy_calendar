# 홈페이지 연결 전용 캘린더 v11

2026-10-08에 v10 소스(저장소 기준 521ec27)에서 복사한 독립 UI다. 원본 v10 파일을 편집하지 않는다. `site-preview/build.py`로 소개 페이지를 재빌드해도 이 파일들은 덮어쓰지 않는다.

- `index.html`: 기존 미리보기 캘린더에서 예약 버튼, 안내 메뉴/팝업과 그 핸들러를 제거했다.
- `calendar-v11-server-cache.js`: v10 런타임 복사본. 버전 전역 이름과 제거된 안내 메뉴의 이벤트 연결만 조정했다.
- `server-calendar-sync.js`: v10 로더 복사본. 데이터 주소만 기존 운영 공개 캐시의 절대 주소로 연결했다.
- `style.css`, `offcanvas-navbar.css`, `swipeCalendar.js`, `browser-guards.js`: 원래 동작을 보존하는 복사본이다.
- `embed.js`: 이미지/링크의 기본 드래그를 막는다. 일정표의 날짜 스와이프는 유지한다.

새로운 예약 처리·DB 원장·동기화 작업은 없다. 원본 v10과 v11은 동일한 공개 예약 데이터를 읽으며, 외부 예약 버튼은 부모 사이트에만 존재한다.
